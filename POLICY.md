# Release Licensing Policy

This policy applies to every dataset published through the release hub.

1. Every released dataset must have a resolved license recorded in its dataset
   card and in the root README release table.
2. When resolving a release, identify **all applicable sources**: the upstream
   data parent(s) of the records, and, where a synthesis model was used to
   produce the records, the published terms of that model.
3. Read the actual terms of each applicable source. A license tag is metadata,
   not the terms; the governing text may change what the tag implies.
4. Where more than one source applies, the license with the **most permissive
   terms for derivative and secondary use** governs the release.
5. Record the comparison in the release report so reviewers can see which
   sources were considered.
